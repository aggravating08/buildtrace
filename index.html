Connect Appwrite

BuildTrace stores your traces in an Appwrite TablesDB table. Add your project details below. These are public project identifiers, not secrets; they stay in this browser.

One-time table setup

In Appwrite, enable anonymous sign-in, add this site’s domain as a Web platform, create a database and a traces table. Add text columns title, project, kind, problem, fix, lesson, tags, url, ownerId; a datetime column loggedAt; and a boolean starred. Enable row-level security and allow authenticated users to create rows.
